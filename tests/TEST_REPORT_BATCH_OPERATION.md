**问题分析**:
```
SyntaxError: Need to install with `app.use` function
at useI18n (vue-i18n)
```

**建议修复**:
在 `vitest.config.ts` 中添加 i18n mock:
```typescript
vi.mock('vue-i18n', () => ({
  useI18n: () => ({
    t: (key: string) => key,
    locale: ref('zh-CN')
  })
}))
```

## 🐛 发现的问题

### 问题 1: BatchActionsBar 组件 i18n 配置问题

**严重程度**: 中  
**影响范围**: 测试覆盖率降低  
**复现步骤**:
```bash
npm test -- tests/unit/batch-actions.test.ts
```

**错误信息**:
```
SyntaxError: Need to install with `app.use` function
at useI18n (vue-i18n)
```

**根本原因**: 
BatchActionsBar.vue 组件使用了 `useI18n()`，但测试环境未配置 vue-i18n 插件。

**建议修复**:
1. 在 `vitest.setup.ts` 中添加 i18n mock
2. 或使用 `vi.mock('vue-i18n')` 拦截 i18n 调用

**预计修复时间**: 30 分钟
