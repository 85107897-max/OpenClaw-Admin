## 二、Cron 可视化编辑器设计详情

### 2.1 设计亮点

- **三种调度模式**: Cron 表达式/每隔 X 时间/指定时间，满足不同用户需求
- **可视化选择器**: 5 个 Cron 字段以按钮组形式展示，支持多选
- **实时预览**: 输入时实时验证，即时显示下次执行时间
- **预设模板**: 5 个常用预设一键应用，降低使用门槛
- **渐进式披露**: 从简单到复杂，按需展示功能

### 2.2 界面结构

```
CronEditor
├── PresetTemplates (5 个预设按钮)
├── ScheduleTypeSelector (3 种模式切换)
│   ├── CronMode (可视化字段选择器)
│   ├── EveryMode (间隔配置)
│   └── AtMode (日期时间选择)
├── NextRunsPreview (5 次执行时间)
└── ActionButtons (重置/保存)
```
