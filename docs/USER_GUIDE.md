## 快速开始

### 首次访问

1. 打开浏览器访问 `http://your-server:3000`
2. 使用默认账号登录：

## 登录与认证

### 登录

1. 访问登录页面
2. 输入用户名和密码
3. 点击"登录"按钮

### 修改密码

1. 点击右上角用户头像
2. 选择"修改密码"
3. 输入旧密码和新密码
4. 确认修改

### 登出

1. 点击右上角用户头像
2. 选择"退出登录"

## 仪表盘

### 功能说明

仪表盘提供系统运行状态的总览：

- **运行总览**: 会话数、用户数、Token 用量等关键指标
- **Token 趋势**: 近 7 天/30 天的 Token 使用量图表
- **会话活跃度**: 活跃会话统计
- **实时事件流**: 系统事件实时监控
- **Top 分布**: Top 模型、渠道、工具统计

### 操作指南

- **时间范围切换**: 点击顶部 "今天/7 天/30 天" 切换统计周期
- **数据下钻**: 点击图表中的具体数据点查看详情
- **刷新数据**: 点击右上角刷新按钮手动刷新

## 会话管理

### 会话列表

查看和管理所有会话：

1. 点击左侧菜单"会话管理"
2. 查看会话列表，包括：
   - 会话 ID
   - 关联智能体
   - 频道
   - 最后活动时间
   - 消息数量
   - Token 用量

### 筛选与搜索

- **关键词搜索**: 输入会话 ID、智能体名称或用户信息
- **智能体筛选**: 选择特定智能体
- **频道筛选**: 选择特定频道（QQ/飞书/钉钉等）
- **状态筛选**: 活跃/空闲/异常

### 会话操作

#### 查看详情
点击会话行查看详细信息，包括：
- 基础信息
- 消息记录
- Token 使用明细
- 关联配置

#### 重置会话
1. 点击会话右侧"重置"按钮
2. 确认重置操作
3. 会话将被清空，Token 计数归零

#### 删除会话
1. 点击会话右侧"删除"按钮
2. 确认删除操作
3. 会话将被永久删除（不可恢复）

## 在线对话

### 进入对话

1. 点击左侧菜单"在线对话"
2. 选择或创建会话
3. 开始聊天

### 消息操作

#### 发送消息
- 在输入框输入内容
- 按 `Enter` 发送
- 按 `Shift + Enter` 换行

#### 斜杠命令
支持以下快捷命令：

| 命令 | 说明 |
|------|------|
| `/new` | 创建新会话 |
| `/skill` | 查看可用技能 |
| `/model` | 切换模型 |
| `/status` | 查看系统状态 |
| `/subagents` | 查看子任务 |

#### 常用语
1. 点击输入框右侧"常用语"按钮
2. 选择预设常用语
3. 常用语将插入输入框

### 消息筛选

- 按角色筛选：用户/助手/系统
- 按时间范围筛选
- 按内容关键词搜索

## 模型管理

### 模型列表

查看和管理所有配置模型：

1. 点击左侧菜单"模型管理"
2. 查看模型列表，包括：
   - 模型名称
   - 提供商
   - API 状态
   - 使用次数
   - 配置时间

### 添加模型

1. 点击"添加模型"按钮
2. 填写模型信息：
   - 模型名称
   - 提供商（OpenAI/Azure/本地等）
   - API Key
   - 基础 URL
   - 模型参数（温度、最大 Token 等）
3. 点击"探测"测试连接
4. 保存配置

### 模型配置

- **默认模型**: 设为默认后，新会话将自动使用该模型
- **编辑配置**: 点击模型右侧"编辑"修改配置
- **删除模型**: 点击"删除"移除模型配置
- **测试连接**: 点击"探测"验证 API 可用性

## 频道管理

### 支持的频道

- **QQ**: QQ 机器人
- **飞书**: 飞书机器人
- **钉钉**: 钉钉机器人
- **企业微信**: 企微机器人

### 配置频道

以飞书为例：

1. 点击左侧菜单"频道管理"
2. 选择"飞书"频道
3. 点击"配置"
4. 填写配置信息：
   - 应用 ID
   - 应用 Secret
   - 验证码
5. 点击"保存"
6. 在飞书后台配置事件订阅地址

### 频道状态

- **已连接**: 频道正常运行
- **未连接**: 需要配置或连接失败
- **认证中**: 正在等待授权
- **错误**: 出现异常，查看错误详情

## 定时任务

### 任务列表

查看和管理定时任务：

1. 点击左侧菜单"定时任务"
2. 查看任务列表，包括：
   - 任务名称
   - 调度表达式
   - 状态
   - 下次执行时间
   - 上次执行时间

### 创建任务

1. 点击"添加任务"
2. 填写任务信息：
   - **任务名称**: 任务标识
   - **描述**: 任务说明
   - **调度方式**:
     - Cron 表达式（如 `0 8 * * *`）
     - 固定间隔（如 `1h`, `30m`）
     - 指定时间（如 `2026-04-11T08:00:00+08:00`）
   - **目标智能体**: 执行任务的智能体
   - **任务内容**: 执行的具体命令或消息
3. 点击"试运行"测试任务
4. 保存任务

### 常用模板

系统提供常用任务模板：

- **每日晨报**: 每天早上 8 点发送日报
- **健康巡检**: 每小时检查系统状态
- **Token 预警**: Token 用量超阈值时告警

### 批量操作

- **批量启用**: 选中多个任务，点击"启用"
- **批量禁用**: 选中多个任务，点击"禁用"
- **批量删除**: 选中多个任务，点击"删除"

## 智能体工坊

### 功能说明

智能体工坊支持多智能体协作场景：

- 创建多智能体场景
- 委派任务给指定智能体
- 智能体间传递消息
- 查看任务执行结果

### 创建场景

1. 点击左侧菜单"智能体工坊"
2. 点击"创建场景"
3. 选择场景模板或从零创建
4. 添加参与智能体
5. 配置智能体角色和权限
6. 保存场景

### 委派任务

1. 进入场景
2. 点击"委派任务"
3. 选择目标智能体
4. 输入任务描述
5. 发送任务
6. 查看执行结果

### 场景模板

系统提供常用场景模板：

- **代码审查**: 开发者 + 审查员协作
- **内容创作**: 写手 + 编辑协作
- **数据分析**: 分析师 + 可视化专家协作

### 功能说明

虚拟公司提供可视化办公场景：

### 区域功能

- **会议室**: 团队会议
- **工位**: 日常工作
- **休息区**: 非正式交流
- **白板区**: 头脑风暴

## 常见问题

### Q: 登录失败怎么办？

A: 检查：
1. 用户名密码是否正确
2. 网络连接是否正常
3. 服务器是否正常运行

### Q: 如何重置密码？

A: 需要管理员权限：
1. 登录管理员账号
2. 进入用户管理
3. 找到对应用户
4. 点击"重置密码"

### Q: 定时任务不执行？

A: 检查：
1. 任务是否启用
2. Gateway 服务是否运行
3. 调度表达式是否正确
4. 查看任务执行日志

### Q: 如何备份数据？

A: 备份以下文件：
1. `data/admin.db` - 数据库文件
2. `.env` - 配置文件
