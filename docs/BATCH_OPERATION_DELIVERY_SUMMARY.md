## 🏗️ 架构设计摘要

### 1. 整体架构
```
前端层 (Vue 3)
├── BatchToolbar.vue - 批量操作工具栏
├── BatchConfirmDialog.vue - 确认弹窗
├── useBatchSelection.ts - 选择逻辑 Composable
└── stores/batch.ts - 批量操作 Store

后端层 (Express)
├── routes/batch.routes.js - 5 个批量操作 API
├── services/BatchService.js - 批量操作服务
└── models/OperationLog.js - 操作日志模型

数据层 (SQLite)
└── operation_logs 表 - 已有 (migration 003)
```

### 2. 核心功能
- ✅ 批量删除 (batch/delete)
- ✅ 批量状态变更 (batch/update-status)
- ✅ 批量导出 (batch/export)
- ✅ 批量分配 (batch/assign)
- ✅ 批量更新 (batch/update)

### 3. 技术要点
- 单次操作上限：500 条
- 超时控制：30 秒
- 事务支持：保证数据一致性
- 权限校验：逐条校验（不批量跳过）
- 操作审计：完整记录到 operation_logs

## 📡 API 接口规范

| 接口 | 方法 | 路径 | 功能 |
|------|------|------|------|
| 批量删除 | POST | /api/batch/delete | 删除多条记录 |
| 批量状态变更 | POST | /api/batch/update-status | 批量更新状态 |
| 批量导出 | POST | /api/batch/export | 导出多条记录 |
| 批量分配 | POST | /api/batch/assign | 批量分配资源 |
| 批量更新 | POST | /api/batch/update | 通用批量更新 |

**统一响应格式**:
```json
{
  "success": true,
  "data": {
    "total": 10,
    "success_count": 8,
    "failed_count": 2,
    "failed_items": []
  },
  "message": "操作成功"
}
```

## ⚠️ 风险评估摘要

### 高风险项 (4 项) - 需立即处理
| 风险 | 缓解措施 |
|------|----------|
| 批量删除误操作 | 二次确认 + 操作日志 |
| 权限绕过 | 逐条权限校验 |
| 大批量操作超时 | 设置上限 500 + 异步处理 |
| 部分失败导致不一致 | 事务 + 补偿机制 |

### 中风险项 (6 项) - 短期处理
- 数据库锁竞争 → 使用事务 + 控制批次大小
- 内存占用过高 → 流式处理
- 批量导出敏感数据 → 字段脱敏
- 恶意批量操作 → 频率限制
- 并发操作冲突 → 乐观锁
- 日志记录失败 → 异步日志 + 重试
