## 一、设计概览

### 1.1 设计目标

为 OpenClaw-Admin 平台设计一个直观、易用、功能完整的 Cron 任务可视化编辑器，降低用户配置定时任务的技术门槛。

### 1.2 用户画像

| 用户类型 | 技术背景 | 使用场景 | 核心需求 |
|---------|---------|---------|---------|
| 初级用户 | 低 | 预设模板快速创建 | 简单、预设、一键配置 |
| 中级用户 | 中 | 自定义简单 Cron | 可视化选择、实时预览 |
| 高级用户 | 高 | 复杂 Cron 表达式 | 完整控制、语法验证 |

### 1.3 设计原则

- **渐进式披露**: 从简单到复杂，按需展示功能
- **即时反馈**: 实时验证、实时预览
- **容错设计**: 友好的错误提示、可撤销操作
- **一致性**: 遵循 Naive UI 设计规范

## 三、详细设计

### 3.1 预设模板区域

**设计要点**:
- 5 个常用预设：每分钟、每小时、每天、每周、每月
- 点击即可应用，无需额外操作
- 高亮显示当前选中的预设

**交互说明**:
```
用户操作: 点击预设按钮
系统响应: 
  - 更新 Cron 表达式
  - 高亮当前选中的预设
  - 刷新执行预览
```

**视觉规范**:
- 按钮尺寸：small (32px 高度)
- 选中状态：primary 类型 (蓝色)
- 未选中状态：default 类型 (灰色)
- 间距：8px

### 3.2 调度类型切换

**设计要点**:
- 三种调度方式：Cron 表达式 / 每隔 X 时间 / 指定时间
- 单选互斥，切换时清空当前配置
- 清晰标识当前选中的模式

**交互说明**:
```
用户操作: 切换调度类型
系统响应:
  - 清空当前表单数据
  - 显示对应模式的编辑区域
  - 重置预览信息
```

### 3.3 Cron 字段可视化选择器

**设计要点**:
- 5 个字段独立展示：分钟、小时、日期、月份、星期
- 每个字段以按钮组形式展示所有可选值
- 支持多选，选中值以 primary 类型高亮
- 提供"全选"/"清空"快捷操作

**交互说明**:
```
用户操作 1: 点击某个值按钮
系统响应 1:
  - 如果当前是 '*'，替换为选中值
  - 如果当前已选中该值，恢复为 '*'
  - 如果当前是其他值，追加到列表中

用户操作 2: 点击"全选"按钮
系统响应 2: 该字段设置为 '*'

用户操作 3: 点击"清空"按钮
系统响应 3: 该字段设置为 '0' (最小值)
```

**视觉规范**:
- 按钮网格布局，每行 8-10 个按钮
- 选中状态：primary 类型
- 未选中状态：default 类型
- 字段标题：font-weight: 500, depth: 3

### 3.4 表达式预览区

**设计要点**:
- 实时显示当前配置的 Cron 表达式
- 支持直接编辑（高级用户）
- 输入失焦时自动验证

**交互说明**:
```
用户操作: 在表达式输入框中输入
系统响应:
  - 实时更新内部状态
  - 失焦时验证表达式合法性
  - 验证失败显示错误提示
  - 验证成功刷新预览
```

**验证规则**:
- 必须为 5 个字段
- 每个字段值在合法范围内
- 能被 cron-parser 库正确解析

### 3.5 下次执行时间预览

**设计要点**:
- 展示接下来 5 次执行时间
- 使用本地时间格式
- 表达式无效时显示友好提示

**视觉规范**:
- 使用 Alert 组件，type: info
- 列表项间距：6px
- 时间格式：YYYY-MM-DD HH:mm:ss

### 3.6 每隔 X 时间模式

**设计要点**:
- 简单的间隔配置界面
- 支持分钟/小时/天三个单位
- 显示等效的 Cron 表达式

**表单配置**:
```
间隔值：数字输入框，最小值 1
单位选项:
  - 分钟 (每 X 分钟)
  - 小时 (每 X 小时)
  - 天 (每 X 天)
```

**等效表达式映射**:
| 间隔 | 单位 | Cron 表达式 |
|-----|------|-----------|
| 1 | 分钟 | * * * * * |
| 5 | 分钟 | */5 * * * * |
| 1 | 小时 | 0 * * * * |
| 2 | 小时 | 0 */2 * * * |
| 1 | 天 | 0 0 * * * |

### 3.7 指定时间模式

**设计要点**:
- 一次性任务配置
- 日期 + 时间组合选择
- 显示明确的执行时间摘要

**表单配置**:
```
日期选择: DatePicker (type: date)
时间选择: TimePicker (format: HH:mm)
```

## 四、状态设计

### 4.1 组件状态

```typescript
interface CronEditorState {
  // 调度类型
  scheduleType: 'cron' | 'every' | 'at'
  
  // Cron 模式状态
  cronExpression: string
  selectedValues: {
    minutes: Set<string>
    hours: Set<string>
    days: Set<string>
    months: Set<string>
    weekdays: Set<string>
  }
  
  // 每隔模式状态
  intervalValue: number
  intervalUnit: 'minutes' | 'hours' | 'days'
  
  // 指定时间模式状态
  specificDate: number | null
  specificTime: number | null
  
  // 验证状态
  isValid: boolean
  errorMessage: string | null
  
  // 预览数据
  nextRunTimes: string[]
}
```

### 4.2 状态流转

```
初始化
  ↓
用户配置 (三种模式互斥)
  ↓
实时验证
  ├─ 有效 → 更新预览 → 可保存
  └─ 无效 → 显示错误 → 阻止保存
```

## 五、交互细节

### 5.1 加载状态

- 组件初始化时显示骨架屏
- 验证过程中显示 loading 图标
- 保存时按钮显示 loading 状态

### 5.2 错误处理

| 错误类型 | 提示文案 | 显示位置 |
|---------|---------|---------|
| 表达式格式错误 | Cron 表达式格式不正确，请检查字段数量 | 表达式输入框下方 |
| 字段值越界 | 分钟值必须在 0-59 范围内 | 对应字段区域 |
| 解析失败 | 无法解析该表达式，请检查语法 | Alert 组件 |

### 5.3 空状态

- 无预设模板时隐藏预设区域
- 无下次执行时间时显示"表达式无效"
- 首次使用时显示引导提示

### 5.4 响应式设计

| 断点 | 布局调整 |
|-----|---------|
| < 768px | 按钮组改为 4 列，隐藏部分预设 |
| 768-1024px | 按钮组改为 6 列 |
| > 1024px | 完整布局，按钮组 8-10 列 |
